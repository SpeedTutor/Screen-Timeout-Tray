# Screen Timeout Tray

A lightweight, free and open-source Windows 11 utility that lets you quickly change your screen timeout settings directly from the system tray.

Designed especially for laptop users, Screen Timeout Tray makes it easy to switch between different display timeout intervals without navigating through Windows Settings.

### Features

- 🖥️ **System Tray Access** – Quickly adjust screen timeout settings from the Windows taskbar.
- 🔋 **Battery & Plugged-In Modes** – Set independent screen timeout durations depending on your power source.
- ⏱️ **Preset Intervals** – Choose from standard Windows timeout intervals, ranging from 1 minute to Never.
- ⚡ **Instant Changes** – Apply new settings immediately using Windows' built-in power management commands.
- 🪶 **Lightweight** – No installation or additional frameworks required.
- 🔓 **Open Source** – Free to use and modify under the MIT License.

### Compatibility

- Windows 11
- Windows 10 (potentially compatible, but not tested)
- PowerShell 5.1 or later

### Getting Started

1. Download the latest release from GitHub.
2. Extract the ZIP archive.
3. Run `Launch.vbs`.
4. Access the application using its system tray icon.
5. Select your preferred screen timeout settings.

Changes are applied directly to your Windows power configuration and persist after closing the application.
